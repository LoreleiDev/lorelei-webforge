# Stack guide

Stack matrix for the router question 2 (WebForge recommends; user picks).

| Stack | Use it when |
|---|---|
| Laravel (Blade/Livewire or Inertia) | All-in-one app with admin and CRUD — router, auth and DB in one place. |
| Next.js + API | Highly interactive app with rich client state. |
| FastAPI + React | Python data/API backend; React frontend for the public site. |
| Astro | Mostly static marketing site — few interactions. |
