# Design ambition checklist

Design quality rules. Must pass before the Design phase ends.

- Distinctive type pairing (two fonts, used well).
- Layered depth (at least one depth layer: elevation, glass, overlay).
- Clear layout rhythm — not a stack of centered blocks.
- One signature motion that respects `prefers-reduced-motion`.
- A plan for imagery or illustration.
- A consistent icon set. No emoji as icons.

Bland test: if the result could be any other site with the logo swapped, it fails.

Revision loop — when the user asks to change the design:

1. Offer three new directions.
2. Regenerate tokens (palette, fonts, radius, shadow).
3. Show a diff of the tokens against the previous version.

If the diff is empty, do not claim the design changed.

Anti-slop (from `ui-ux-pro-max`): stays active — no generic purple gradients, no default Inter-only look.
